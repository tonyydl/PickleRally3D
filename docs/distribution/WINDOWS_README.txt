Pickle Rally 3D - Windows x86_64 prototype

Extract the ZIP, then double-click PickleRally3D.exe. Godot does not need to be installed.
Game data is embedded in the EXE.

Controls
WASD: move and aim at contact
Left mouse: Drive / serve / next rally
Right mouse: Dink near the net, Drop farther back
Space: Lob
Shift + left mouse: Smash when the ball is high enough
Esc: pause / resume
R: restart the match

Traditional side-out scoring: first to 11, win by 2.
Keyboard and mouse required.
