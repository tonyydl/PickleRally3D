# 五種打法與直接擊球操作設計

狀態：使用者已選擇方案 A，沿用既有 Godot 4.7.2／Windows／GDScript 專案。這份文件補充初版設計，記錄本次的操作與驗收依據。數值為本次實作決策，可依試玩調整。

## 目的與範圍

讓玩家能以不同球速、弧度與落點打出 Dink、Drive、Lob、Drop、Smash，而不只是換擊球名稱。保留 WASD 移動／觸球瞬間瞄準、左鍵發球與下一回合、Esc 暫停、R 重開；維持兩次落地、Kitchen、界內外與傳統單打計分。

不加入自由旋轉、蓄力、跳躍、線上連線或更多進階打法。發球保持獨立的合法對角球路；五種打法不改變規則，也不能繞過 Kitchen 限制。

## 操作方案

比較過 A（按鍵直接擊球）與 B（1～5 選打法後再左鍵擊球）；使用者選擇 A，減少移動中切換步驟。

| 操作 | 意圖／實際球路 |
| --- | --- |
| 左鍵 | Drive；發球／準備／回合結果時仍負責繼續流程 |
| 右鍵 | Soft：觸球時球員距網不超過 3.4 m 為 Dink，否則 Drop |
| Space | Lob；僅回合進行中有效，按住不連發 |
| Shift＋左鍵 | Smash；觸球高度至少 1.65 m 且幾何上可向下過網，否則改用 Drive 並解釋原因 |
| WASD | 移動；觸球瞬間決定左右與深淺，未輸入時取安全中央 |

右鍵／Space 不負責發球或跳過結果畫面，避免誤觸。0.3 秒提前擊球緩衝儲存擊球意圖，放開按鍵不取消；方向及 Dink／Drop 站位判斷取實際觸球時的狀態。每次按鍵最多擊球一次，暫停／結束／重開清除意圖。

## 球路與判定

| 球路 | 目標與速度／弧度 |
| --- | --- |
| Drive | 中深場，水平速度以約 12 m/s 為起點；必要時只增加足以過網的弧度 |
| Dink | 對方 Kitchen 內約 0.9～1.7 m；低速、短距離、接近網帶的安全弧線 |
| Drop | 從中後場送入 Kitchen，落點同屬短區，飛行時間較 Drive 長以卸速 |
| Lob | 深場約 4.8～6.05 m；至少約 4.8 m 的高弧頂，迫使對手退後 |
| Smash | 可觸及的高球，快速向下攻向中深場；起始垂直速度必須為負且球路能過網 |

球路計算統一放入獨立 `shots.gd`；返回實際種類、目標、飛行時間與降級提示，仍交給 `flight.gd` 做確定性重力、反彈與連續碰撞。重力、球半徑、落地反彈係數不依打法任意更換。自動弧線輔助屬易上手的原型取捨。

## AI 與回饋

AI 使用相同的球路與規則入口：一般以 Drive 穩定回球；近網面對短球時可打 Soft；玩家上網時偶爾 Lob；可及高球且規則允許時可 Smash。保留追球速度、反應時間與兩次落地限制，不瞬移或越過觸球範圍。

HUD 顯示完整按鍵、右鍵目前對應 Dink／Drop、扣殺可用提示，以及最後成功擊球的球路和擊球方。球路以顏色、音高、揮拍幅度區分；球本身維持黃色，落點圈仍為黃色，出球目標圈顯示預計球路顏色。

## 驗收

- 五種球路有可測的速度／弧頂／落點差異；每種合法代表球路均過網並落在預計目標。
- 實際 Godot 輸入事件驗證左鍵、右鍵、Space、Shift＋左鍵；提前輸入仍保留種類且不重複擊球。
- Kitchen 內落地球可打 Dink；Kitchen 截擊與兩次落地違例仍正常判定。
- AI 能回應高吊／短球，且一般中央 Drive 對打至少 20 拍；玩家仍能以落點得分。
- 暫停、終局與重開不殘留新輸入狀態；完整既有測試通過，GPU 截圖確認操作說明與高球可讀。
