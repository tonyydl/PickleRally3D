# 網頁版低效能模式設計

狀態：依 2026-10-23 使用者回饋改為自動調整。沿用 Godot 4.7.2／Compatibility renderer。

## 目的與範圍

網頁版若持續低 FPS，自動降低場景繪圖負擔，無須玩家尋找設定。正常流暢時保留目前畫質。不承諾軟體繪圖能達到硬體加速效能。

## 方案

- 手動切換：實作簡單，但使用者認為必須自行操作不合適。
- **啟動時辨識已知軟體繪圖器，並以 FPS 備援：採用。** Chrome 可提供 SwiftShader 名稱時立即降畫質；瀏覽器因隱私不提供可靠名稱時，依實際 FPS 判斷。

## 行為

- 僅在網頁版檢查遊戲畫布的 WebGL renderer；若名稱包含 SwiftShader、Basic Render Driver 或 llvmpipe，立即啟用低效能模式。無法確認繪圖器時，在視窗有焦點且遊戲未暫停的完整 2 秒視窗平均低於 25 FPS 時啟用。失焦或暫停時丟棄未完成的樣本，避免背景分頁節流造成誤判。
- 啟用後關閉球場方向光陰影，隱藏 benches 與遠景樹木等裝飾；球場線、球網、角色、球、落點提示與 HUD 保持可見。
- 一個遊戲工作階段只會自動降畫質一次，避免畫質反覆跳動；重新載入網頁才重新偵測。重新開始比賽不重設畫質。
- 不加入手動設定或 3D 解析度縮放。Godot 的內建 3D resolution scaling 不適用於此專案的 Compatibility renderer。

## 驗收

- 持續低 FPS 自動啟用模式；正常 FPS、短暫卡頓、暫停和背景分頁不會觸發。
- 啟用後重新開始比賽仍保持低效能模式；重新載入網頁恢復預設畫質並重新偵測。
- 兩種模式下擊球、規則、球場辨識與 HUD 相同；headless 專案檢查與現有測試通過。
